# Temporal Regulatory Knowledge Graph

Ontology and LLM-based Temporal Knowledge Graph for detecting changes in government regulations, finding applicable rule versions, and analyzing amendment impact. Final Year Project.

## Problem Statement

Laws, rules, notifications and amendments are spread across many documents and change over time. It is hard to know which rule currently applies and what changed from an earlier version.

## Objectives

- Model laws, amendments, requirements, departments and services in an ontology.
- Build a temporal Knowledge Graph with validity periods for each rule version.
- Detect amendments and analyze which services or requirements are affected.
- Answer natural-language questions with evidence-grounded explanations using an LLM.

## Scope

Cyber law and AI law (as advised by the supervisor).

## Key Features

- Amendment and change detection
- "Which rule applied in year X?" version lookup
- Impact analysis of amendments
- Natural-language question answering with source evidence
